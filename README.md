# THIRANEX INTERNSHIP – FULL STACK WEB DEVELOPMENT


## TASK 1: PERSONAL PORTFOLIO WEBSITE

### What Was Developed:
A clean, responsive, and professional personal portfolio website showcasing actual personal and academic credentials. It includes an interactive user interface with animated skill bars, project modal popups, certification breakdowns, a printable resume view, and a full-stack contact form connected to MongoDB Atlas.

### Tech Stack:
- Frontend: React.js, Vite, CSS3
- Backend: Node.js, Express.js
- Database: MongoDB Atlas (Mongoose)

### Key Features:
1. Home / Hero section with professional introduction and career objective.
2. About Me section highlighting engineering background and interests.
3. Education section (Kongu Engineering College - 8.63 CGPA, HSC - 94.8%, SSLC - 94.2%).
4. Technical Skills categorized into Programming Languages, Frontend, Backend, Databases, Tools, and Core CS.
5. Previous Projects showcase (ShopEasy, Sarcasm Detection, Capacity Connect, IoT Bird & Rat Detection).
6. Certifications & Achievements gallery with credential details.
7. Working Contact API storing messages directly into MongoDB Atlas.

## TASK 2: TASK MANAGEMENT APPLICATION



### What Was Developed:
A full-stack task manager featuring secure token-based user authentication and complete CRUD operations. Users can register, log in, create tasks with categories and priorities, view their own tasks, toggle completion states, edit task information, and delete tasks.

### Tech Stack:
- Frontend: React.js, Vite, CSS3, Lucide Icons
- Backend: Node.js, Express.js, REST API
- Database: MongoDB Atlas (Mongoose)
- Authentication: JWT (JSON Web Tokens), bcryptjs password hashing

### Key Features:
1. User Registration & Login with password encryption.
2. Add Tasks with title, description, category, priority (Low/Medium/High), and due date.
3. View & Filter Tasks by All, Pending, and Completed with live counter badges.
4. Mark Tasks as Completed or Pending via instant status toggle.
5. Edit task information and save changes directly to MongoDB.
6. Delete tasks with user ownership authorization.
7. Secure JWT authentication middleware protecting task data.

## TASK 3: E-COMMERCE WEB APPLICATION



### What Was Developed:
A functional e-commerce web application with catalog browsing, category filtering, a product details modal, persistent shopping cart management, and a demo Cash on Delivery (COD) checkout workflow that registers orders in MongoDB Atlas.

### Tech Stack:
- Frontend: React.js, Vite, CSS3, Lucide Icons
- Backend: Node.js, Express.js, REST API
- Database: MongoDB Atlas (Mongoose)

### Key Features:
1. Product Listing displaying items with prices (INR), stock status, and categories.
2. Category Filters (Audio, Wearables, Accessories, All).
3. Product Details Modal showing high-resolution image, specifications, and live stock.
4. Shopping Cart Drawer with quantity increments (+), decrements (-), and item deletion.
5. Persistent Cart storing selections across browser refreshes via localStorage.
6. Checkout Form capturing customer name, email, phone number, and delivery address.

## TASK 4: BLOG PLATFORM WITH COMMENTS


### What Was Developed:
A full-stack blogging platform with user authentication, article authoring, feed discovery, reading views, author-restricted edit/delete operations, and an interactive commenting system for readers.

### Tech Stack:
- Frontend: React.js, Vite, CSS3, Lucide Icons
- Backend: Node.js, Express.js, REST API
- Database: MongoDB Atlas (Mongoose)
- Authentication: JWT, bcryptjs

### Key Features:
1. User Registration & Login for authors.
2. Article Publishing with custom titles, content, and engineering categories.
3. Article Feed with excerpt previews, author attribution, dates, and comment counts.
4. Article Reader Modal with full-text display.
5. Author Edit & Delete controls restricted to the post creator.
6. Real-time Commenting System enabling readers to post feedback with timestamps.
7. All blog posts, users, and comments permanently saved in MongoDB Atlas.
